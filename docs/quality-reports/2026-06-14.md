## Action Items (ordered by priority)

### CRITICAL

1. **[CRITICAL] Duplicate Stripe webhook routes** — `src/app/api/webhook/stripe/route.ts` and `src/app/api/webhooks/stripe/route.ts` both exist and diverge. The `/webhook/stripe` version skips signature verification and falls back to `'sk_test_placeholder'`/`'whsec_placeholder'`. One of these is the live endpoint registered in Stripe; the other is a dead route that will silently accept unsigned payloads if discovered. Delete the unverified one and consolidate.

2. **[CRITICAL] Cron auth guard commented out** — `/api/cron/abandoned/route.ts` has its Authorization check commented out (`// if (req.headers.get('Authorization') !== ...`). Any unauthenticated caller can trigger it on production. Restore the guard or delete the route.

3. **[CRITICAL] Missing node_modules in worktree** — The `beautiful-wilbur-35db93` worktree has no `node_modules`, making `tsc`, `eslint`, and `npm audit` all fail. TypeScript reports 101 errors that are entirely module-resolution errors, not real bugs, but it prevents CI from catching genuine type issues. Run `npm ci` in this worktree or configure the project to share node_modules with the main worktree.

### HIGH

4. **[HIGH] `next-question/route.ts` is 581 lines** — exceeds the 300-line ceiling. The route handles TMDB fetching, LLM prompting, niche scoring, pool selection, and response formatting in a single file. Extract utility functions to `src/lib/engine/` to reduce cognitive load and enable unit testing.

5. **[HIGH] `scan/page.tsx` is 570 lines** — same issue on the front-end side. Break into sub-components.

6. **[HIGH] 25 explicit `any` types in source** — Concentrated in API routes (TMDB API responses, Stripe event objects, Firebase snapshot callbacks). Add typed interfaces for TMDB `Movie`, `Video`, and `Keyword` shapes. Stripe's SDK already exports correct types — use them.

7. **[HIGH] No unit test coverage for core engine logic** — `src/lib/engine/baselinePool.ts` (138 lines), `src/lib/engine/subGenres.ts` (192 lines), `src/lib/taste/deriveTaste.ts` contain the core recommendation math with zero test files. Regressions here break the entire product silently.

### MEDIUM

8. **[MEDIUM] 10 moderate npm vulnerabilities** — `postcss < 8.5.10` (XSS via unescaped `</style>`) lives inside `next`'s own dependency tree; `uuid < 11.1.1` (buffer bounds) is in `firebase-admin`'s chain. Both require major-version bumps of `next` or `firebase-admin` to fix safely. Track in issue; fix in next planned upgrade window.

9. **[MEDIUM] 7 loose QA/audit `.js` scripts in project root** — `persona-swarm-30.js`, `persona-audit.js`, `visual-persona-test.js`, etc. are development QA harnesses (~60 KB combined) committed to the repo root. Move to `scripts/qa/` and add to `.gitignore` or a dedicated branch, or convert to proper Playwright tests.

10. **[MEDIUM] `/api/emails/route.ts` is a stub** — the entire email-sending logic is commented out (`/* await resend.emails.send(... */`). It always returns `{ success: true }` regardless. Either wire it up with Resend or delete the route to avoid false signals.

11. **[MEDIUM] `sessionToken.ts` falls back to a hardcoded secret** — `const SECRET_KEY = process.env.SESSION_SECRET || 'fallback-secret-for-dev-only-do-not-use-in-prod'`. If `SESSION_SECRET` is not set in production (easy to miss), sessions can be forged. Add a startup assertion that throws if the env var is absent in non-development.

12. **[MEDIUM] Stripe API version mismatch** — `'2026-05-27.dahlia'` is used in two routes but TypeScript reports it is not assignable to the SDK's expected type `'2026-03-25.dahlia'`. This means either the installed `stripe` package is older than expected or the version string is wrong. Resolve to avoid silent runtime breakage.

13. **[MEDIUM] 47 console statements** — Acceptable for early-stage but should be replaced with structured logging (e.g. `pino`) before scaling, especially in API routes where secrets may appear in log output.

### LOW

14. **[LOW] 1 TODO comment** — `src/app/api/webhooks/stripe/route.ts:29` — integrate Resend for abandoned-cart email. Low priority but tracked for completeness.

15. **[LOW] `baseline-keywords.json` and `baseline-pool-verified.json`** committed to repo root (14 KB and 15 KB). These are data files; consider moving to `src/data/` for cleaner project layout.

16. **[LOW] `tsconfig.tsbuildinfo` committed** — incremental build cache file; should be in `.gitignore`.
